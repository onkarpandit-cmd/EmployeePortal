
# Employee Management Web App

A web application built using ASP.NET Core MVC and C# to manage employee records.

## Features

- CRUD operations for employee records
- Search employees
- Filter by department and employee type
- Pagination
- Form validation
- SQL Server database integration using Entity Framework Core

## Technologies Used

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML, CSS, Bootstrap
- Git and GitHub

## Project Setup

1. Clone this repository.
2. Open the solution in Visual Studio.
3. Configure the SQL Server connection string.
4. Apply database migrations if required.
5. Run the application.

## Learning Outcomes

- Understanding MVC architecture
- Implementing CRUD operations
- Working with Entity Framework Core
- Integrating SQL Server with ASP.NET Core
- Using Git and GitHub for version control
